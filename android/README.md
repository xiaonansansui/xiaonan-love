# 小楠爱情 - Android App

## 用 Android Studio 打开这个文件夹

1. 下载安装 [Android Studio](https://developer.android.com/studio)
2. 打开 Android Studio → Open → 选 `android/` 这个文件夹
3. 等待 Gradle 同步完成
4. 连接手机 → 点绿色 ▶ 运行

## 包名
`com.xiaonan.lovepage`

## 功能
- 自动加载网页：https://xiaonansansui.github.io/xiaonan-love/
- WebView 全屏沉浸式
- Firebase 实时同步自动生效
- 支持返回键回退
